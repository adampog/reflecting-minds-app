## Agreed current beta boundaries
- Mobile-first PWA for phones, optional home-screen install, basic tablet/desktop support.
- Small invited beta; no formal research pilot.
- Approximately nine provisional entry doors; reviewed pre-produced audiovisual scenarios with deterministic branching and a hybrid live action/generated-media production direction.
- No live AI; no in-app feedback prompts; no working group, invitation, or shared-journal features in beta.
- Local-first reflection, explicit on-device save and user-controlled deletion/export, no required account, essential operational telemetry only (no reflection text or detailed personal activity tracking).
- Seven flexible stages: Entry, Notice, Motivation, Compare, Discern, Respond, Review. User may skip, decline, pause, disagree or exit.
- Product, engineering, content and privacy owners must be accountable before release. Production build and release have NOT been established by mockup QA.
