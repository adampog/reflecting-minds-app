# RMA entry icon set v0.1.2

Original hand-built SVG icon set for the selected Layered Paper direction. All 25 icons use a 24×24 viewBox, 1.75 px rounded `currentColor` strokes and no fills. The sprite and labeled preview are included. Stage glyphs are navigation symbols only; none indicates a completed state or reward.

This version makes `review` visually distinct from `report` and adds `door`, `privacy` and `leave` without figures, eyes, shields, locks or ticks. The 21 other individual icon SVGs carry over byte-for-byte from v0.1.1. Review-only proposal; not an adopted app set.
