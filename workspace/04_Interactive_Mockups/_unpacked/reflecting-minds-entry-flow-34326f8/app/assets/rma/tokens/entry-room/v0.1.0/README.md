# RMA entry and room tokens v0.1.0

Proposed tokens derived from the selected Layered Paper direction A. The entry palette is warmer; the room palette remains restrained. There is no success/reward token and no completion-state colour shift. System font fallbacks are used; no font files are bundled.

This is a review-only demonstrator, not an adopted app theme. Values, contrast checks and the original direction source are in `tokens.json` and `CONTRAST-CHECK.json`.
