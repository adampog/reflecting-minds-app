# Reflecting Minds v0.2 mockup: tap-through viewer

This is a low-fidelity phone mockup of the v0.2 specification. All content is fictional. It has no AI, makes no network requests and has no backend.

1. Extract `Reflecting_Minds_v02_Tap_Through_Project_Review_2026-10-21.zip` and open the extracted `reflecting-minds-v02-viewer` folder.
2. Open `app/index.html` in a browser.
3. Narrow the window to phone width, about 390 px, or use the browser's device view.

Optional links:
- `app/index.html?door=divided-group` opens a single door from an entry link.
- `app/index.html?door=old-route-pack` shows the safe fallback for a retired link.
- `app/index.html#saved` opens the saved sessions.

"Save on this device" uses this browser's local storage only. Use "Delete all" on the Saved screen to clear it.

See `v02-mockup-brief.md` for what the mockup shows, what changed, and what was not tested.
